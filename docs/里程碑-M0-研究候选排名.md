# M0 研究候选排名证据门禁

日期：2026-09-13

## 现状与根因

首页原“现在买什么”和“实时买点雷达”虽然有免责声明，但仍使用“买入区间、止损、目标、建议仓位”等交易推荐语言。免责声明不能阻止调用方或页面把未通过样本外验证的分数包装成推荐；同时验证报告仅保存在进程内，重启、验证失败或只运行随机对照后都可能没有可用策略证据。

## 本里程碑契约

`GET /api/realtime/picks` 增加 `evidence`：

- `status`：当前固定落在 `not_passed`。进程内报告缺失、验证任务失败或只运行随机对照，都不能抹去研发计划 v1.1 已登记的 6 折负结果。
- `recommendation_allowed`：当前阶段固定为 `false`。即使单次报告平均超额为正，也不能越过研发计划要求的预注册、多折独立留出、成本压力与置信区间门槛。
- `summary`：给出当前证据状态和不能推荐的原因。
- `primary_horizon`、`mean_excess_pct`、`report_generated_at`、`evidence_source`：提供可追溯摘要。默认引用研发计划 v1.1 已登记的 3 日平均超额 -0.390%、1/6 折为正。

随机/最差对照不视为策略验证。主口径平均超额不大于零时明确标记 `not_passed`；正值只标记 `insufficient_evidence`。

## 前端要求

首页和原雷达页统一改为“研究候选排序”。首页每张卡显示数据日期、候选理由、风险标签、失效条件和证据状态。模型价格线与风险预算使用研究语言，不得显示为下单、止损、目标或仓位建议。
