# 股票软件优化方案：投资决策工作台

版本：2026-09-14

## 目标

把现有的行情、指标、基本面、估值和 DeepSeek 解释能力组织成一条可复核的研究流程。用户输入股票代码后，软件应同时回答：企业质量如何、证据是否充分、当前价格隐含什么预期、悲观情景会损失多少、哪些事实会推翻结论，以及何时需要重新检查。

系统只做研究决策辅助。确定性代码负责数字，DeepSeek 负责归纳与反方审查；解释模型不能修改计算结果、证据门禁或交易状态。

## 设计原则

1. **价格与价值分开**：技术强弱用于判断交易拥挤和时机，企业质量与现金流用于判断长期价值。
2. **结论与置信度分开**：质量分不是上涨概率；数据缺失、过期或只有单一来源时必须单列。
3. **先看隐含预期**：除三情景 DCF 外，反解当前价格要求的增长率，避免只问“目标价是多少”。
4. **强制反证**：每份结论都展示反对证据、失效条件与复核触发器。
5. **组合约束优先**：单只股票再好，也要受单票上限、行业集中度、流动性和最大损失约束。
6. **拒绝伪精确**：现金流、净负债等关键数据缺失时标明估计，不把示例假设包装成事实。

## 分阶段执行

### P0：投资决策工作台（本轮执行）

- 新增前端“投资研究”页面，打通基本面快照、质量评分、证据置信度、三情景估值和七项统一输出。
- 所有估值假设可见、可改，并标注为使用者假设。
- 新增反向估值接口，计算当前股价隐含的营收增长率及可解范围。
- 页面同时展示支持证据、反对证据、失效条件和数据时点。
- 保持实盘功能关闭，不从研究页直接下单。

验收：后端新增纯函数和接口测试；前端类型检查与生产构建通过；运行中的服务可访问新接口和新页面。

### P1：财务三表增强

- 接入现金流量表与资产负债表，保存经营现金流、资本开支、货币资金、有息负债、商誉和股东权益。
- 自动计算自由现金流、净负债、经营现金流/净利润、商誉/净资产，并返回字段来源与报告期。
- 数据不齐时继续允许人工假设，但页面醒目标注估计口径。

验收：质量指标覆盖率提升；估值不再默认净负债为零；数据库迁移可回滚。

### P2：研究记录与复核

- 保存每次研究的冻结证据包、假设、模型版本和结论。
- 同一标的支持版本差异对比。
- 新财报、价格偏离或论点失效时生成复核提醒。

### P3：DeepSeek 投资委员会

- 在同一证据包上依次运行主分析和反方审查。
- 用固定案例测试数字引用、诱导看多、关键字段删除和价格变化。
- 只有解释质量实测提高后才默认开启，模型输出不能新增证据包外的数字。

### P4：组合闭环

- 将研究结论映射为模拟盘调仓草案。
- 加入行业暴露、相关性、最大回撤预算与流动性约束。
- 延续现有审批、样本外证据和实盘显式授权门禁。

## 本轮交付边界

本轮完成 P0。P1 需要新增数据采集与数据库字段，适合在 P0 的交互和接口稳定后单独迁移。任何策略在没有通过预注册样本外验证前，都继续显示为研究候选，不标记为可交易策略。
